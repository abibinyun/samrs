# 🏗️ Stack Frontend SAMRS

**Core & State Management**

* React 18 + Vite + TypeScript
* Redux Toolkit + RTK Query → API & caching

**Routing & Tables**

* TanStack Router → navigation & role-based routes
* TanStack Table → headless table + server-side pagination

**UI & Styling**

* Shadcn/ui → accessible UI components
* Tailwind + clsx + tailwind-merge + tailwindcss-animate
* Lucide-react → iconography
* Optional: custom utility classes untuk branding / multi-tenant

**Forms & Validation**

* React Hook Form + Zod (+ @hookform/resolvers)

**Utilities & Helpers**

* date-fns → date manipulation
* react-hot-toast → notifications / toast
* react-i18next → multi-language support

---

# 🔹 Pattern / Best Practices

1. **Routing**

   * TanStack Router untuk route / layout / protection / role-based
   * Jangan pakai loader untuk API, gunakan RTK Query
   * ProtectedRoute wrapper untuk role-based access

2. **Data Fetching**

   * Semua API via RTK Query hooks
   * Component subscribe langsung ke query hook → loading / error handled di component

3. **Tables**

   * TanStack Table headless → styling via Tailwind / shadcn/ui
   * Server-side pagination / filtering / sorting → connect dengan RTK Query

4. **Forms**

   * React Hook Form + Zod → schema-based validation
   * Inline errors via component → toast untuk global feedback

5. **Styling / Branding**

   * Shadcn/ui + Tailwind → override className jika mau theme custom
   * Tailwind-merge + clsx → merge / conditional class

6. **Multi-tenant**

   * Inject `tenantId` di API headers via RTK Query
   * Theme / colors / branding bisa di wrapper layout per tenant
