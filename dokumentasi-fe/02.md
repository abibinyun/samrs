Ini adalah struktur **"Enterprise-Grade"**. Dengan 100 modul, tantangan terbesarnya bukan hanya *coding*, tapi **navigasi kode** dan **kohesi**. Struktur ini memecah modul menjadi unit-unit fungsional yang sangat terprediksi.

Berikut adalah implementasi kode untuk satu modul (contoh: **Modul Patient**) menggunakan pola yang Anda minta:

---

### 1. API: `modules/patient/api/patientApi.ts`

Fokus hanya pada definisi *contract* dengan Go Backend.

```typescript
import { baseApi } from "@/store/api/baseApi";
import { Patient, PatientResponse } from "../types";

export const patientApi = baseApi.injectEndpoints({
  endpoints: (builder) => ({
    getPatients: builder.query<PatientResponse, { tenantId: string; page: number }>({
      query: (params) => ({
        url: `/v1/patients`,
        params,
      }),
      providesTags: ["Patient"],
    }),
  }),
});

export const { useGetPatientsQuery } = patientApi;

```

---

### 2. Hooks: `modules/patient/hooks/usePatientList.ts`

Ini adalah **"Otak"** dari fitur. View tidak boleh tahu cara mengolah data, semua ditaruh di sini.

```typescript
import { useState } from "react";
import { useGetPatientsQuery } from "../api/patientApi";

export const usePatientList = (tenantId: string) => {
  const [page, setPage] = useState(1);
  const { data, isLoading, isFetching } = useGetPatientsQuery({ tenantId, page });

  const handleNextPage = () => setPage((prev) => prev + 1);
  const handlePrevPage = () => setPage((prev) => Math.max(prev - 1, 1));

  return {
    patients: data?.items ?? [],
    meta: data?.meta,
    isLoading: isLoading || isFetching,
    pagination: { page, handleNextPage, handlePrevPage },
  };
};

```

### 3. Views: `modules/patient/views/PatientList.view.tsx`

Murni UI. Ia menerima *props* yang sudah "matang" dari Controller.

```tsx
import { PatientTable } from "../components/PatientTable";
import { Button } from "@/components/ui/button";

interface Props {
  data: any[];
  loading: boolean;
  onNext: () => void;
  onPrev: () => void;
}

export const PatientListView = ({ data, loading, onNext, onPrev }: Props) => (
  <div className="space-y-4">
    <div className="flex justify-between items-center">
      <h1 className="text-2xl font-bold">Daftar Pasien</h1>
      <div className="space-x-2">

        <Button onClick={onNext} variant="outline">Next</Button>
      </div>
    </div>

  </div>

```

### 4. Routes: `modules/patient/routes.tsx`

Modul mendaftarkan jalurnya sendiri. Ini kunci agar `src/routes/index.tsx` tidak penuh sesak.

```tsx
import { createRoute } from "@tanstack/react-router";
import { tenantRoute } from "@/routes"; // Import parent rute /$tenantId
import PatientModule from "./index";

export const patientRoutes = createRoute({
  getParentRoute: () => tenantRoute,
  path: "/patient",
  component: PatientModule,
});

```

---

### 5. Index (Controller): `modules/patient/index.tsx`

Perekat antara **Hooks** dan **Views**.

```tsx
import { useParams } from "@tanstack/react-router";
import { usePatientList } from "./hooks/usePatientList";
import { PatientListView } from "./views/PatientList.view";

export default function PatientModule() {
  const { tenantId } = useParams({ from: "/$tenantId" });
  const { patients, isLoading, pagination } = usePatientList(tenantId);

  return (
    <PatientListView 
      data={patients} 
      loading={isLoading} 
      onNext={pagination.handleNextPage}
      onPrev={pagination.handlePrevPage}
    />
  );
}

```

### Mengapa Struktur Ini "Menang" untuk 100 Modul?

1. **Modularitas Tanpa Batas**: Jika Anda ingin menghapus modul `patient`, Anda cukup menghapus 1 folder dan 1 baris di rute utama. Tidak ada dependensi yang tertinggal.
2. **Type-Safe Across Layers**: Folder `types/` dan `schemas/` memastikan dari API sampai Form input semuanya tervalidasi oleh TypeScript dan Zod.
3. **Refactor-Friendly**: Ingin mengganti tabel dengan library lain? Cukup buka `views/` atau `components/`. Ingin mengganti logika pencarian? Cukup buka `hooks/`.
4. **Team Scaling**: Anda bisa menugaskan 5 developer berbeda untuk mengerjakan 5 modul berbeda tanpa mereka pernah membuka file yang sama (kecuali file routing pusat).

### Rekomendasi Tambahan:

Untuk 100 modul, gunakan **Barrel Exports** di setiap folder. Misalnya, buat file `modules/patient/hooks/index.ts`:

```typescript
export * from './usePatientList';
export * from './usePatientDetail';

```

Sehingga di `index.tsx` Anda cukup menulis: `import { usePatientList } from "./hooks";`.
