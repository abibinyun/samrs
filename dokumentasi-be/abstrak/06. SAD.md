# **3. Security & Compliance Document**

## **Security & Compliance Document (SAD) - SAMRS**

### **A. Authentication & Authorization**

1. **JWT Engine:** Menggunakan **RS256** (Asymmetric) atau **HS256**. Expiry: **24 Jam**. Payload: `user_id`, `tenant_id`, `role_id`.
2. **Hashing:** Password wajib menggunakan **Bcrypt** (Cost 10+). Tidak ada penyimpanan teks polos.
3. **RBAC Middleware:** Setiap request divalidasi berdasarkan `permission_slug`. Jika gagal, return `403 Forbidden`.

### **B. Data Privacy & Isolation**

1. **Tenant Isolation:** Setiap query SQL wajib menyertakan filter `tenant_id` secara implisit melalui Middleware/Scopes di GORM untuk mencegah kebocoran data antar RS.
2. **Sanitization:** Proteksi terhadap SQL Injection dengan *Parameter Binding* dan XSS protection pada input string.

### **C. Audit & Reliability**

1. **Immutable Audit Logs:** Tabel `audit_trails` hanya mendukung operasi `INSERT`. Tidak ada `UPDATE` atau `DELETE` pada log ini.
2. **Soft Delete:** Penghapusan data menggunakan kolom `deleted_at` untuk menjaga integritas sejarah data medis.

### **D. Infrastructure**

1. **Rate Limiting:** Maksimal 100 request/menit per IP untuk mencegah brute-force.
2. **Secrets Management:** Seluruh kredensial (DB, JWT Key) dikelola via Environment Variables (`.env`).
