# **3. Deployment & Project Scaffolding Plan - SAMRS**

### **A. Struktur Folder (Clean Architecture)**

Kita akan menggunakan pola pemisahan tanggung jawab agar saat tim Anda bertambah, kode tidak saling tumpang tindih.

```text
samrs-backend/
├── cmd/
│   └── api/
│       └── main.go              # Entry point aplikasi
│   └── seed/
│       └── main.go              # Entry point seeder
├── internal/
│   ├── app/                     # Wiring DI + router
│   ├── config/                  # DB, hooks, guards, logger
│   ├── delivery/http/           # Handler + middleware + httputil
│   ├── domain/                  # Entity & model
│   ├── repository/              # Data access per modul
│   ├── seed/                    # Seeder logic
│   ├── test/                    # Test mocks/util
│   └── usecase/                 # Business logic per modul
├── pkg/                         # Helper & util umum
├── scripts/                     # Script tooling (smoke test, dll)
├── uploads/                     # File upload (local dev)
├── logs/                        # File log (local dev)
├── docs/                        # Dokumentasi backend
├── api_test.http                # Koleksi API test manual
├── .env.example                 # Template variabel lingkungan
├── docker-compose.yml           # Orkestrasi Database
└── go.mod                       # Go module

```

---

### **B. Environment Configuration (.env)**

Kita tidak akan menulis *password* di dalam kode. Semua diatur melalui file `.env`.

* `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASS`, `DB_NAME`
* `JWT_SECRET`: Kunci enkripsi token.
* `APP_PORT`: Port aplikasi (8080).
* `ENV`: Mode development atau production.

---

### **C. Deployment Strategy (Dockerized)**

Dengan menggunakan Docker, kita memastikan sistem berjalan stabil di laptop Anda maupun di server produksi.

1. **Database Container:** PostgreSQL 15 dengan data yang persisten (tidak hilang saat komputer mati).
2. **Application Container:** Menggunakan *Multi-stage Build* untuk menghasilkan file *binary* Go yang sangat ringan (hanya sekitar 15-20MB).

---

### **D. Development Workflow (Cara Kita Bekerja)**

1. **Setup Infrastructure:** Menjalankan Docker Compose.
2. **Database Migration:** Menjalankan script SQL untuk membentuk tabel (RBAC & Audit Trail).
3. **Core Development:** Membangun Middleware Tenant & Auth.
4. **Module Development:** Membangun fitur Aset dan Lokasi satu per satu.
5. **Integration:** Menyambungkan ke Frontend React.
