# **2. DBML & Full API Specification**

## **Technical Design Document (TDD) - SAMRS Part 2**

### **A. DBML (Database Markup Language)**

*(Copy-paste ke dbdiagram.io)*

```dbml
Table tenants {
  id uuid [pk]
  name varchar
  slug varchar [unique]
  status varchar
  created_at timestamp
}

Table users {
  id uuid [pk]
  tenant_id uuid [ref: > tenants.id]
  role_id integer [ref: > roles.id]
  username varchar [unique]
  password_hash text
  is_active boolean
  created_at timestamp
}

Table roles {
  id integer [pk, increment]
  tenant_id uuid [ref: > tenants.id]
  name varchar
  is_system boolean
}

Table permissions {
  id integer [pk, increment]
  slug varchar [unique]
  module varchar
}

Table role_permissions {
  role_id integer [ref: > roles.id]
  permission_id integer [ref: > permissions.id]
}

Table locations {
  id integer [pk, increment]
  tenant_id uuid [ref: > tenants.id]
  parent_id integer [ref: > locations.id]
  name varchar
  type varchar
}

Table assets {
  id uuid [pk]
  tenant_id uuid [ref: > tenants.id]
  location_id integer [ref: > locations.id]
  code varchar
  name varchar
  status varchar
  purchase_date date
}

Table audit_trails {
  id bigint [pk, increment]
  tenant_id uuid [ref: > tenants.id]
  user_id uuid [ref: > users.id]
  action varchar
  table_name varchar
  record_id varchar
  old_data jsonb
  new_data jsonb
  created_at timestamp
}

```

### **B. API Specification (MVP Scope)**

#### **1. Auth Module**

* **POST `/auth/login**`: Payload `{username, password}` -> Success `200 {token, user_object}`.
* **GET `/auth/me**`: Success `200 {user_data, permissions_list}`.

#### **2. User & RBAC**

* **GET `/users**`: List staff per tenant.
* **POST `/users**`: Create user. Payload `{username, password, role_id}`.
* **GET `/roles**`: List roles & permissions mapping.

#### **3. Asset & Location (Core)**

* **GET `/assets**`: Support query `?status=&location_id=&search=`.
* **POST `/assets**`: Create asset. Payload `{code, name, brand, location_id, status}`.
* **PATCH `/assets/:id**`: Partial update status/lokasi. Trigger Audit Trail.
* **DELETE `/assets/:id**`: Soft delete (update `deleted_at`).
